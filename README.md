## 💡 Repository Content Overview

### 🧩 Data Structures & Algorithms (DSA)
- **`GENERAL_DSA_CONCEPTS.part1` & `GENERAL_DSA_CONCEPTS.part2`** — Comprehensive core algorithms, sorting, searching, time/space complexities, dynamic programming, and problem-solving patterns (split into two ~53MB parts to bypass GitHub's 100MB file limit).
- **`DSA GRAPHS INTERVIEW MATERIAL.docx`** — Graph representations, BFS/DFS traversals, shortest path algorithms (Dijkstra, Bellman-Ford), topological sort, and cycle detection.
- **`DSA TREES MATERIAL.docx`** — Binary Trees, BSTs, AVL, Segment Trees, Trie structures, tree traversals, and common tree interview problems.
- **`DSA LINKED LIST CONCEPTS INTERVIEW.docx`** — Singly/Doubly linked lists, cycle detection (Floyd's Algorithm), reversing lists, and pointer manipulation.
- **`LEETCODE PRAC CONCEPTS INTERVIEW.docx`** — Practical pattern-based approaches for solving top LeetCode interview problems.

### 🗄️ Database Management Systems (DBMS) & SQL
- **`DATABASE PREP.docx`** — Full database architecture, indexing, normalization (1NF to 5NF), ACID properties, and transaction management.
- **`DBMS_Full_Notes INTERVIEW.pdf`** — Complete theoretical and practical DBMS interview prep guide.
- **`Database HUMAN WRITTEN notes.pdf`** — Detailed handwritten notes on relational algebra, query execution plans, and schema design.
- **`JOINS DATABASE INTERVIEW CONCEPTS.docx`** — Deep dive into SQL Joins (INNER, LEFT, RIGHT, FULL, CROSS, SELF) with execution visualizers and query optimization tips.

### 💻 Core Computer Science & OOP
- **`OOP CONCEPTS INTERVIEW.docx`** — Four pillars of Object-Oriented Programming (Abstraction, Encapsulation, Inheritance, Polymorphism), SOLID principles, and design patterns.
- **`OS CONCEPTS INTERVIEW.docx`** — Operating System fundamentals: process scheduling, threads, concurrency, deadlocks, memory management (paging/segmentation), and virtual memory.
- **`programming concepts.docx`** — Fundamental programming paradigms, memory allocation (heap vs stack), scope, and execution models.
- **`Interview Prep Guide.docx`** — General strategy guide, behavioral interview preparation, and technical communication frameworks.

### 🐳 DevOps & Cloud Technologies
- **`docker CONCEPTS.docx`** — Containerization concepts, Dockerfiles, images, containers, networking, and volumes.
- **`docker and kubernates INTERVIEW MATERIAL.docx`** — Kubernetes architecture (Pods, Deployments, Services, Ingress), container orchestration, and CI/CD pipelines.

### 🌐 Web Development & Programming Languages
- **`JAVASCRIPT DEVELOP CONCEPTS.docx`** — Modern JavaScript (ES6+), Event Loop, Promises, Async/Await, Closures, Prototypes, and DOM manipulation.
- **`JAVA SCRIPT COURSE.docx`** — Core JavaScript fundamentals course material.
- **`PYTHON VS FLASK DIFF.docx`** — Python language features vs Flask micro-web framework architecture and REST API development.
- **`web scraping CONCEPTS.docx`** — Web scraping tools, BeautifulSoup, Selenium, rate limiting, and HTTP request structures.

### 🧠 Artificial Intelligence & Machine Learning
- **`CNN CONCEPTS INTERVIEW.docx`** — Convolutional Neural Networks, filter kernels, pooling layers, activation functions, transfer learning, and deep learning architectures.

## 🛠️ Reassembling Split Files

To combine `GENERAL_DSA_CONCEPTS.part1` and `GENERAL_DSA_CONCEPTS.part2` back into `GENERAL DSA CONCEPTS.docx`:

- **Windows (Command Prompt)**:
  ```cmd
  copy /b GENERAL_DSA_CONCEPTS.part1 + GENERAL_DSA_CONCEPTS.part2 "GENERAL DSA CONCEPTS.docx"
  ```
- **Linux / macOS (Terminal)**:
  ```bash
  cat GENERAL_DSA_CONCEPTS.part1 GENERAL_DSA_CONCEPTS.part2 > "GENERAL DSA CONCEPTS.docx"
  ```
